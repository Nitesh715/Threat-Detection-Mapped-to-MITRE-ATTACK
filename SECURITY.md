# Security Policy

## Supported Versions

The latest code on the `main` branch is supported.

## Reporting a Vulnerability

Please report vulnerabilities privately through this repository's GitHub **Security** tab using **Report a vulnerability**, when that option is available. Do not post exploit details in a public issue.

If private reporting is unavailable, contact the maintainer privately through the contact method on the GitHub profile before sharing technical details. Include the affected version or commit, impact, and steps to reproduce. Do not include real malware samples, credentials, or third-party personal data.
